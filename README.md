# M-A · 11/11 💍

تطبيق جوال خاص بينك وبين شريكك — مستوحى من فكرة سناب شات لكن بحساب مغلق بينكم اثنين فقط. فيه:

- 📸 **لحظاتنا**: صور تختفي بعد المشاهدة أو بعد 24 ساعة، مثل سناب شات.
- 🏡 **بيتنا**: بيت وحديقة مشتركة تكبرون فيها مع بعض — تزرعون نباتات، تشترون أثاث، توسّعون البيت، وتخصصون شخصياتكم. كل هذا يشتغل بنقاط (🪙) تكسبونها من الألعاب.
- 🎮 **ألعاب ثنائية**: صراحة ولا تحدي، ارسم وخمّن (Pictionary)، وكم تعرفني (مقارنة إجابات).
- 💡 **أفكارنا**: لوحة أفكار ومواعيد ومهام تضيفونها مع بعض.
- 🔐 حسابين فقط مرتبطين برمز دعوة سري — ما فيه أي مستخدم ثالث يقدر يشوف بياناتكم.

## التقنية المستخدمة (كلها مجانية)

- **React Native + Expo** (كود واحد لـ iOS و Android)
- **Firebase** (Authentication + Firestore + Storage) — الخطة المجانية (Spark) كافية جداً لحسابين
- **expo-router** للتنقل بين الشاشات
- **GitHub** لحفظ الكود

## 1) تجهيز Firebase (مرة وحدة بس)

1. روح إلى https://console.firebase.google.com وسجّل دخول بحساب جوجل.
2. اضغط **إنشاء مشروع (Add project)** واختر اسم مثل `couple-app`.
3. داخل المشروع، من القائمة الجانبية:
   - **Build → Authentication** → فعّل **Email/Password** كطريقة تسجيل دخول.
   - **Build → Firestore Database** → أنشئ قاعدة بيانات في وضع **Production** (اختر أقرب موقع لكم، مثل `me-central2`).

> ⚠️ **ملاحظة مهمة**: Firebase Storage (لتخزين الصور كملفات) صار يتطلب خطة **Blaze** المدفوعة (تحتاج بطاقة بنكية حتى لو ما راح تُحسب عليكم فلوس فعلياً). عشان يبقى التطبيق **مجاني 100% وبدون أي بطاقة**، صور "لحظاتنا" تُخزَّن كـ base64 مضغوط مباشرة داخل Firestore بدل Storage. الجودة أبسط شوي من صورة كاملة الدقة لكنها تكفي تماماً للفكرة. إذا حبيتوا لاحقاً صور/فيديوهات بجودة أعلى، تقدرون تترقّون لخطة Blaze وتفعّلون Storage (فيه ملف `storage.rules` جاهز لهذا الغرض).
4. من ⚙️ **Project settings → General**، تحت "Your apps" اضغط أيقونة الويب `</>` وسجّل تطبيق ويب جديد (اسمه مثلاً `coupleapp-web`). راح يعطيك كائن `firebaseConfig` فيه القيم.
5. انسخ ملف `.env.example` إلى ملف جديد اسمه `.env` وعبّي القيم من `firebaseConfig`:

```bash
cp .env.example .env
```

6. ثبّت أدوات Firebase وارفع قواعد حماية Firestore الموجودة بالمشروع (`firestore.rules`) عشان تحددوا مين يقدر يوصل لبياناتكم:

```bash
npm install -g firebase-tools
firebase login
firebase init firestore   # اختر المشروع اللي أنشأته، ووافق يستخدم firestore.rules الموجود
firebase deploy --only firestore:rules
```

> هذي الخطوة **ضرورية**: قاعدة البيانات أُنشئت في وضع Production (كل شي مرفوض افتراضياً)، فلازم ترفعوا `firestore.rules` قبل ما يشتغل تسجيل الدخول والاقتران.

## 2) تشغيل التطبيق محلياً

```bash
npm install
npm run start
```

راح يفتح لك Expo Dev Tools. حمّل تطبيق **Expo Go** على جوالك (من App Store أو Google Play) وامسح رمز QR اللي يطلع بالطرفية.

- أول شخص يفتح التطبيق يسوي **حساب جديد** ثم يختار "أنشئ رمز دعوة" ويشارك الرمز مع شريكه.
- الشخص الثاني يسوي حساب ويدخل نفس الرمز في "شريكي عنده رمز دعوة".
- بعدها الاثنين يشوفون نفس البيانات (اللحظات، البيت، الألعاب، الأفكار) لحظياً.

## 3) رفع المشروع على GitHub

```bash
git add -A
git commit -m "الإعداد الأولي للتطبيق"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```

> تأكد إن ملف `.env` ما ترفعه أبداً (هو مستثنى تلقائياً في `.gitignore`) لأنه فيه مفاتيح مشروعكم.

---

## 4) بناء نسخة حقيقية للجوال (اختياري)

بعد ما تتأكدون إن كل شي شغال بـ Expo Go، تقدرون تسوّون نسخة APK/AAB مجانية عبر **EAS Build**:

```bash
npm install -g eas-cli
eas login
eas build:configure
eas build --platform android --profile preview
```

EAS عندها خطة مجانية فيها عدد بنايات شهرية محدود، تكفي لتطبيق شخصي بينكم.

## هيكلة المشروع

```
app/                  شاشات التطبيق (expo-router)
  (auth)/              تسجيل دخول / حساب جديد / اقتران
  (tabs)/              التبويبات الرئيسية بعد تسجيل الدخول
    index.tsx           لحظاتنا (الكاميرا والمشاركة)
    world.tsx            بيتنا (الحديقة + الأثاث + الشخصيات)
    games/                الألعاب الثلاث
    ideas.tsx             لوحة الأفكار
    profile.tsx           الحساب
lib/                  التعامل مع Firebase (auth, firestore, storage)
context/              حالة تسجيل الدخول والزوجين (AuthContext)
constants/            الألوان + محتوى الألعاب + كتالوج البيت
firestore.rules        قواعد حماية قاعدة البيانات
storage.rules           قواعد حماية تخزين الصور
```
